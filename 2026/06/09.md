## 取り組んだ課題一覧
- AWS と Terraformで実現するInfrastructure as Code

## わかったこと
### ロードバランサー（ALB）

#### ロードバランサーとは
複数のサーバーへトラフィックを分散する仕組み。

#### リスナー
- ALBが受信するポートを定義する
- 例: HTTP(80), HTTPS(443)

#### ターゲットグループ
- ALBの転送先となるサーバー群
- EC2、ECS、Lambdaなどを登録できる

#### ターゲットグループアタッチメント
- ターゲットグループへEC2を登録する

主な属性:
- target_group_arn
- target_id

### Route53

#### Route53のデータ構造
- Hosted Zone
- Record

#### CNAMEレコード
別ドメインへ転送する。

例:
www.example.com → example.com

#### Aレコード
IPアドレスを指定する。

例:
example.com → 192.168.1.10

### ACM

#### ACMとは
- SSL/TLS証明書を管理するサービス
- リージョンごとに作成が必要

補足:
CloudFrontで利用する場合は us-east-1 に作成する。

### S3

#### データ構造
- Bucket
- Public Access Block
- Bucket Policy
- Policy Document

### CloudFront

#### CloudFrontとは
CDN（キャッシュサーバー）サービス

#### Origin
配信元サーバー

例:
- S3
- ALB

#### Behavior
アクセスルールを定義する

例:
- / → S3
- /api/* → ALB

#### OAI
Origin Access Identity
CloudFrontからのみS3へアクセスさせる仕組み

### Launch Template

#### 主な設定
- AMI
- キーペア
- セキュリティグループ
- IAMロール
- EBS

#### Block Device Mappings
EBSボリューム設定

#### バージョン管理
Launch Templateはバージョン管理される

### Auto Scaling Group

#### Auto Scaling Groupとは
EC2を自動増減させるサービス

例:
CPU使用率80%以上でEC2を追加

### Module

#### Moduleとは
Terraformのリソースをまとめて再利用可能にしたもの

プログラミングにおける関数に近い

#### メリット
- 再利用しやすい
- 可読性向上
- 管理しやすい

#### 呼び出し例

module "vpc" {
  source = "./modules/vpc"
}

### IAM Policy

#### IAM Policyとは
権限を定義するJSONドキュメント

#### aws_iam_policy
TerraformでIAMポリシーを作成するリソース

### IAM Group

#### IAM Group
複数ユーザーへ権限をまとめて付与する

#### Group Policy Attachment
グループへポリシーを付与する

### IAMユーザーとPGP

#### PGPとは
Pretty Good Privacy の略

公開鍵暗号方式を利用する

#### 用途
IAMユーザー作成時の初期パスワード暗号化

#### GPGコマンド例

鍵生成:
gpg --full-generate-key

公開鍵出力:
gpg --armor --export user@example.com

### IAMユーザー

#### IAMユーザー作成

resource "aws_iam_user" "user" {
  name = "sample-user"
}
