## わかったこと
### Terraform 補足解説

#### CIDR Blockとは

CIDR BlockはIPアドレスの範囲を表す。

例:

```text
10.0.0.0/16
```

利用可能IP数:

```text
65536個
```

サブネットに分割して利用する。

#### サブネット

サブネットはVPCを分割したネットワーク。

##### Public Subnet

- インターネットへ接続可能
- WebサーバーやALBなどを配置する

##### Private Subnet

- インターネットから直接アクセス不可
- RDSや内部システムを配置する

#### ルートテーブル

通信先によって転送先を決定する。

例:

```text
10.0.0.0/16 -> local
0.0.0.0/0 -> Internet Gateway
```

#### セキュリティグループ

AWSの仮想ファイアウォール。

特徴:

- ステートフル
- 戻り通信は自動許可

#### プレフィックスリスト

複数のCIDRをまとめて管理する仕組み。

### RDS

#### パラメータグループ

DBパラメータを管理する。

例:

- max_connections
- log_statement
- character_set

#### オプショングループ

DBエンジン固有機能を有効化する。

#### RDS削除防止

```hcl
deletion_protection = true
```

誤削除防止に利用する。

### tfstate

Terraformが管理対象の状態を保持する重要なファイル。

保存内容:

- リソースID
- 属性値
- 依存関係

#### Git管理しない理由

- 機密情報を含む可能性がある
- コンフリクトしやすい
- 破損リスクがある

実務ではS3 + DynamoDBを利用することが多い。

### Terraform Import

既存リソースをTerraform管理へ取り込む。

```bash
terraform import aws_instance.web i-123456789
```

### depends_on

Terraformが自動判定できない依存関係を定義する。

```hcl
depends_on = [
  aws_iam_role.example
]
```

### count と for_each

#### count

```hcl
count = 3
```

#### for_each

```hcl
for_each = {
  dev = "t3.micro"
  prod = "t3.large"
}
```

実務では for_each が推奨される。

### lifecycle

#### prevent_destroy

```hcl
lifecycle {
  prevent_destroy = true
}
```

#### ignore_changes

```hcl
lifecycle {
  ignore_changes = [tags]
}
```

### terraform graph

依存関係を可視化する。

```bash
terraform graph
```

### For式

```hcl
[for name in var.users : upper(name)]
```

### 三項演算子

```hcl
var.env == "prod" ? "large" : "small"
```
