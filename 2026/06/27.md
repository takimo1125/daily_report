## わかったこと
### Prisma

Node.js 環境で使用できる ORM（Object Relational Mapper）。

TypeScript と相性が良く、安全にデータベースを操作できる。

特徴

- 自動マイグレーション
- 高速で効率的なクエリ操作
- Prisma Client が内部で効率的な SQL に変換して実行
- 型安全（Type Safety）
- 自動補完が充実している

---

### Volta

Node.js のバージョン管理ツール。

プロジェクトごとに Node.js や npm、pnpm のバージョンを固定できる。

例

```bash
volta install node
volta install npm
```

---

### Prisma コマンド

### prisma format

schema.prisma のフォーマットを行う。

```bash
npx prisma format
```

---

### prisma db seed

初期データ（Seed データ）をデータベースへ投入する。

```bash
npx prisma db seed
```

---

### prisma generate

schema.prisma を基に Prisma Client を生成する。

```bash
npx prisma generate
```

---

### Prisma Studio

GUI でデータベースを確認・編集できるツール。

```bash
npx prisma studio
```

---

### prisma migrate dev

開発環境向けのマイグレーションを実行する。

- マイグレーションファイルを作成
- データベースへ適用
- Prisma Client の生成

```bash
npx prisma migrate dev
```

---

### prisma migrate deploy

本番環境向けにマイグレーションを適用する。

```bash
npx prisma migrate deploy
```

---

### prisma db push

schema.prisma の内容をデータベースへ反映する。

マイグレーションファイルは作成しない。

開発時のみ利用することが多く、本番環境では基本的に使用しない。

```bash
npx prisma db push
```

---

### prisma reset

データベースを削除して作り直す。

開発環境専用。

```bash
npx prisma migrate reset
```

---

### datasource

使用するデータベースを定義する。

例

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

---

### generator

Prisma Client の生成方法を定義する。

例

```prisma
generator client {
  provider = "prisma-client-js"
}
```

---

### model

データベースのテーブル定義を行う。

例

```prisma
model User {
  id   Int    @id @default(autoincrement())
  name String
}
```

---

### 属性（Attribute）

モデルやフィールドの振る舞いを設定する。

よく使う属性

- @id
- @default()
- @unique
- @updatedAt
- @relation

例

```prisma
id Int @id @default(autoincrement())
```

---

### CRUD

### Create

データを作成する。

```ts
await prisma.user.create({
  data: {
    name: "Taro"
  }
});
```

---

### createMany

複数件まとめて登録する。

```ts
await prisma.user.createMany({
  data: [
    { name: "A" },
    { name: "B" }
  ],
  skipDuplicates: true
});
```

### skipDuplicates

重複データをスキップする。

---

### findUnique

一意制約（@unique）が付いている列で検索する。

```ts
await prisma.user.findUnique({
  where: {
    id: 1
  }
});
```

---

### findMany

複数件取得する。

```ts
await prisma.user.findMany();
```

---

### findFirst

条件に一致する最初の1件を取得する。

```ts
await prisma.user.findFirst({
  where: {
    name: "Taro"
  }
});
```

---

### update

データを更新する。

```ts
await prisma.user.update({
  where: {
    id: 1
  },
  data: {
    name: "Jiro"
  }
});
```

---

### upsert

存在すれば更新、存在しなければ作成する。

```ts
await prisma.user.upsert({
  where: {
    id: 1
  },
  update: {
    name: "Jiro"
  },
  create: {
    id: 1,
    name: "Taro"
  }
});
```

---

### delete

データを削除する。

```ts
await prisma.user.delete({
  where: {
    id: 1
  }
});
```

---

### Zod

TypeScript 向けのバリデーションライブラリ。

入力値の検証を行う。

例

```ts
const schema = z.object({
  name: z.string(),
  age: z.number()
});
```

---

### Payload

HTTP リクエストやレスポンスで保持するデータのこと。

例

```json
{
  "name": "Taro",
  "age": 20
}
```

---

### HttpOnly Cookie

JavaScript からアクセスできない Cookie。

XSS（クロスサイトスクリプティング）対策として利用される。

例

```
Set-Cookie: token=xxxxx; HttpOnly; Secure; SameSite=Lax
```

特徴

- JavaScript から取得できない
- サーバーのみ読み書きできる
- セッション管理でよく利用される
