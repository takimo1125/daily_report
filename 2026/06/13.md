## わかったこと
### ディレクトリ構成

- /app
  - アプリケーションのルート、コンポーネント、ロジックを配置
- /app/lib
  - ユーティリティ関数やデータ取得関数を配置
- /app/ui
  - UIコンポーネントを配置
- /public
  - 画像などの静的アセットを配置
- next.config.ts
  - Next.js の設定ファイル

### CSS Modules

CSSクラスをコンポーネント単位でローカルスコープ化できる。

メリット:
- スタイル競合防止
- 保守性向上

### 画像最適化

Next.jsでは next/image を利用して画像を自動最適化できる。

width と height を指定するとレイアウトシフトを防止できる。

###ルーティング

フォルダ + page.tsx でルートを作成する。

## レイアウト

レイアウトはページ遷移時に再レンダリングされない。
これを部分レンダリングという。

### Server Components

メリット:
- Promise対応
- サーバー側で重い処理を実行可能
- DBへ直接アクセス可能

### リクエストウォーターフォール

前のリクエスト完了後に次を実行するパターン。

### 並列データ取得

Promise.all() を利用する。

### Static Rendering

ビルド時にHTMLを生成する。

メリット:
- 高速
- SEOに強い
- サーバー負荷軽減

### Dynamic Rendering

リクエスト時にHTMLを生成する。

メリット:
- リアルタイムデータ
- ユーザーごとの表示

### Streaming

loading.tsx または Suspense を利用する。

### Loading Skeleton

読み込み中のプレースホルダーUI。

### Route Groups

URLへ影響を与えずにルートをグループ化できる。

### Suspense

コンポーネント単位でストリーミング制御できる。

### defaultValue と value

value:
React管理

defaultValue:
ブラウザ管理

### Debounce

一定時間入力が止まった後に処理を実行する。

### Server Actions

'use server' を使用してサーバー上で処理を実行する。

メリット:
- API不要
- セキュリティ向上

### FormData

formData.get() で値を取得する。

### Zod

TypeScript向けバリデーションライブラリ。

### UUID

メリット:
- 一意性保証
- 推測困難

### error.tsx

error と reset を受け取る。

### アクセシビリティ

重要項目:
- セマンティックHTML
- ラベル
- フォーカス管理

### 認証と認可

認証:
本人確認

認可:
権限管理
