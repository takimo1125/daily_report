## わかったこと
### Next.js ストリーミング・キャッシュ・App Router メモ

### Streaming SSR

ページ全体ではなく、一部ずつ HTML を返す仕組み。

### Suspense

非同期処理の完了を待つ間、フォールバック UI を表示する仕組み。

### Client Component と Server Component

Server Component のメリット

- JavaScript の送信量削減
- SEO に有利
- データ取得が容易

データ取得はできるだけ末端の Server Component で行う。

Client Component はできるだけ末端で利用する。

Composition Pattern の利用が推奨される。

### キャッシュ

Next.js には主に 4 種類のキャッシュがある。

### Request Memoization

同一リクエスト内で同じ URL を fetch した場合に再利用される。

### Data Cache

異なるリクエスト間でも利用されるキャッシュ。

### Full Route Cache

Static Rendering で生成された HTML と RSC Payload を保存する。

### Client Router Cache

ブラウザメモリに RSC Payload を保存する。

### ファイルシステム規約

### page.tsx

ページを定義する。

### layout.tsx

共通レイアウトを定義する。

### loading.tsx

ローディング UI を定義する。

### error.tsx

ページ単位のエラー画面。

### global-error.tsx

アプリ全体のエラー画面。

### not-found.tsx

404 ページを定義する。

### route.ts

API エンドポイントを定義する。

### middleware.ts

リクエスト前に実行される共通処理。

### public

静的ファイル配置ディレクトリ。

### Dynamic Route Segments

動的パラメータ付きルート。

例

app/users/[id]/page.tsx

### Route Groups

URL に影響を与えずにルートをグループ化する。

### Parallel Routes

同一レイアウト内で複数ページを表示する機能。

### Intercepting Routes

別ルートを割り込んで表示する機能。

### CRUD

Read は Server Component を利用する。

Create / Update / Delete は Server Actions を利用する。

### useActionState

フォーム処理を簡潔に実装できる React Hook。

### Link

ページ遷移を行うコンポーネント。

### Image

画像最適化機能付きコンポーネント。

### useRouter

ページ遷移や履歴操作を行う Hook。

### router.replace()

履歴を置き換える。

### router.refresh()

Server Component を再取得する。

### usePathname

現在のパスを取得する。

### useSearchParams

クエリパラメータを取得する。

### cookies()

Cookie の取得・更新・削除を行う。

### redirect()

ページ遷移を行う。

### notFound()

404 を表示する。

### router.push()

履歴を残してページ遷移する。

### revalidatePath()

キャッシュされたページを再検証する。

例

revalidatePath('/dashboard')
