## わかったこと
### Forループ

#### 基本形

GoのForループは、以下の3つの要素で構成される。

```go
for 初期化; 条件; 後処理 {
}
```

| 要素 | 説明 |
|---|---|
| 初期化 | 最初に1回だけ実行 |
| 条件 | ループごとに評価 |
| 後処理 | 各ループの最後に実行 |

#### サンプル

```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

#### 実行順

1. `i := 0`
2. `i < 5`
3. 処理実行
4. `i++`
5. 条件再評価

### Forループのスコープ

#### ループ内で宣言した変数

```go
for i := 0; i < 3; i++ {
    fmt.Println(i)
}

// fmt.Println(i) // エラー
```

`i` はForループ内でのみ有効。

#### 外側で宣言する場合

```go
i := 0

for ; i < 3; i++ {
    fmt.Println(i)
}

fmt.Println(i)
```

ループ外でも使用可能。

### Forの省略記法

#### 条件のみ

```go
i := 0

for i < 5 {
    fmt.Println(i)
    i++
}
```

Goではwhileが存在しないため、この形式がwhile相当。

#### 無限ループ

```go
for {
    fmt.Println("loop")
}
```

#### 用途

- Webサーバー
- 常駐プロセス
- イベント待機
- メッセージ監視

### break と continue

#### break

ループ終了。

```go
for i := 0; i < 10; i++ {
    if i == 5 {
        break
    }

    fmt.Println(i)
}
```

#### continue

現在の処理を飛ばして次へ。

```go
for i := 0; i < 5; i++ {
    if i == 2 {
        continue
    }

    fmt.Println(i)
}
```

### ラベル付きbreak

ネストしたループをまとめて抜けられる。

```go
Outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if j == 1 {
            break Outer
        }
    }
}
```

### Goの早期リターン

#### 悪い例

```go
if err == nil {
    if user != nil {
        process(user)
    }
}
```

#### 良い例

```go
if err != nil {
    return err
}

if user == nil {
    return errors.New("not found")
}

process(user)
```

#### メリット

- ネスト減少
- 読みやすい
- エラー処理が明確

### switch文

#### 基本

```go
switch day {
case "Mon":
    fmt.Println("Monday")
case "Tue":
    fmt.Println("Tuesday")
default:
    fmt.Println("Other")
}
```

### switchの特徴

- break不要
- 一致したcaseだけ実行
- 上から順に評価

### 複数case

```go
switch n {
case 1, 2, 3:
    fmt.Println("small")
}
```

### 条件式なしswitch

```go
switch {
case score >= 90:
    fmt.Println("A")
case score >= 70:
    fmt.Println("B")
}
```

if-elseの代替としてよく使う。

### fallthrough

通常Goのswitchは自動終了する。

`fallthrough` を使うと次のcaseも実行。

```go
switch n {
case 1:
    fmt.Println("one")
    fallthrough
case 2:
    fmt.Println("two")
}
```

### defer

#### 基本

```go
func read() {
    file, _ := os.Open("a.txt")
    defer file.Close()

    // 処理
}
```

### deferの特徴

- 関数終了時に実行
- return直前に動く
- panic時も実行される

### deferの実行順

LIFO（後入れ先出し）。

```go
defer fmt.Println(1)
defer fmt.Println(2)
defer fmt.Println(3)
```

実行順：

```text
3
2
1
```

### deferの引数評価

```go
x := 1

defer fmt.Println(x)

x = 100
```

出力：

```text
1
```

defer時点で評価される。

### panic と recover

#### panic

強制終了。

```go
panic("error")
```

#### recover

panicを回復。

```go
func main() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println(r)
        }
    }()

    panic("error")
}
```

### append

```go

```

### append時の再確保

容量不足時、新しい配列を作成。

```go
s := make([]int, 0, 2)

s = append(s, 1)
s = append(s, 2)
s = append(s, 3)
```

3回目で再確保。

### クロージャ

#### 基本

```go
func counter() func() int {
    count := 0

    return func() int {
        count++
        return count
    }
}
```

### クロージャの特徴

```go
c1 := counter()
c2 := counter()

fmt.Println(c1())
fmt.Println(c1())
fmt.Println(c2())
```

出力：

```text
1
2
1
```

状態を保持している。

### クロージャの用途

- カウンター
- ID生成
- キャッシュ
- コールバック
- 設定保持
