## わかったこと
### TypeScript

TypeScriptはAltJS（Alternative JavaScript）と呼ばれるJavaScriptの代替言語の1つです。

- JavaScriptに型システムを追加した言語
- 開発時にエラーを発見しやすい
- 最終的にはJavaScriptへ変換して実行する
- この変換をトランスパイルと呼ぶ

### Node.js

Node.jsはJavaScriptの実行環境です。

ブラウザ以外でもJavaScriptを実行できます。

### npm

Node.js標準のパッケージマネージャー。

用途

- ライブラリ管理
- ツール管理
- スクリプト実行

### 開発モードと本番モード

#### 開発モード

- ソースコード変更時に自動反映
- デバッグログを出力
- エラー内容を詳細表示

#### 本番モード

- 高速動作を優先
- 不要なログを出力しない
- セキュリティを重視

### テスト

#### Unit Test

関数やクラス単位のテスト

#### API Test

Web APIの入出力を検証

#### E2E Test

ブラウザ操作を自動化しシステム全体を確認

### ビルド

ビルドとはソースコードから本番環境で利用する成果物を作る工程。

#### コンパイル

#### トランスパイル

TypeScript → JavaScriptなど

#### バンドル

複数ファイルをまとめる

#### パッケージング

配布形式へまとめる
