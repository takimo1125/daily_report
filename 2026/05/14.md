### 1. スライスの重複排除（Unique の実装）

#### 基本戦略
`slices` パッケージ（Go 1.21+）の `Sort` と `Compact` を組み合わせる。

#### 手順

```go
slices.Sort(mi)
return slices.Compact(mi)
```

### ポイント

- `Compact` は「隣り合う重複」しか削除できない
- そのため、事前に `Sort` で同じ値を並べる必要がある
- `slices.Compact(mi)` は、重複を削除した「新しいスライス」を返す
- 元のスライスも書き換わるが、戻り値を受け取ることが必須

### 2. for range のコピー挙動と更新の注意点

#### 問題の性質

```go
for _, user := range users
```

この `user` は、スライス要素の「値のコピー」である。

#### 失敗例

```go
user.Age = 44
```

これで変更されるのは、ループ内の一時コピーのみ。

元の `users` スライスには反映されない。

---

#### 解決策（2パターン）

##### ① インデックス経由で更新する

```go
for i := range users {
    users[i].Age = 44
}
```

- インデックス経由で元のメモリ位置を直接更新する

---

##### ② ポインタのスライスを使う

```go
[]*User
```

- コピーされるのは「実体」ではなく「メモリアドレス」
- アドレス経由で実体を書き換えられる

```go
for _, user := range users {
    user.Age = 44
}
```

この場合は反映される。

### 3. fmt.Stringer インターフェース

#### 仕組み

`fmt.Println` などは、対象の型が

```go
String() string
```

を実装しているか確認する。

---

#### 挙動

実装されていれば、その戻り値を表示に使う。

---

#### 例

```go
func (u User) String() string {
    return fmt.Sprintf("ID: %d, Name: %s", u.ID, u.Name)
}
```

---

#### 用途

```go
fmt.Printf("%v", obj)
```

の出力を、人間が読みやすい形式にできる。

例：

```text
ID: 1, Name: Tarou
```

---

### 4. `&` と `*` の違い（ポインタの基本）

| 記号 | 役割 | 意味 |
|---|---|---|
| `&` | アドレス取得 | 変数のメモリアドレスを取得する |
| `*int` | ポインタ型 | 「int のアドレスを保持する型」 |
| `*p` | デリファレンス | ポインタの指す先の値を読み書きする |

---

#### 例

```go
x := 10

p := &x   // x のアドレス取得
fmt.Println(*p) // 10

*p = 20
fmt.Println(x) // 20
```

---

### 5. fmt パッケージのフォーマット（復習）

| フォーマット | 意味 |
|---|---|
| `%v` | デフォルト形式 |
| `%+v` | フィールド名付きで表示 |
| `%T` | 型を表示 |
| `%p` | ポインタ（アドレス）を表示 |

---

#### 例

```go
fmt.Printf("%v\n", user)
fmt.Printf("%+v\n", user)
fmt.Printf("%T\n", user)
fmt.Printf("%p\n", &user)
```
