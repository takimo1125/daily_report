## わかったこと
### Go基礎まとめ

### 概要
- GoはGoogleによって2009年に開発されたプログラミング言語
- C言語の開発者たちが、よりシンプルで効率的な開発を目指して設計

### Goでできること
- Webアプリケーション開発
- クラウドインフラ開発
- CLIツール作成

### なぜGoなのか
- 性能と開発速度のバランスが良い
  - ビルドが速い / 実行が速い
- 並行処理とネットワークIOに強い
  - goroutine / channel / context
- 単一バイナリで配布可能
  - クロスプラットフォーム / 依存が少ない
- 標準ライブラリ・ツールが充実

### クラウドネイティブとの関係
- CNCFプロジェクトの多くがGo製
- 大規模プロダクトで利用（決済 / 配信 / インフラ監視・運用）
- バックエンド / SREと相性が良い

### パッケージ
- コードをまとめる単位（機能ごとにグループ化し再利用しやすくする）
- 例：fmt（入出力）/ math（数学）/ net/http（Web通信）

### プログラムの開始
- `package main` が必要
- `main関数` から実行

### 出力
- fmt.Println：改行あり出力
- fmt.Printf：フォーマット指定
  - %f（浮動小数）/ %t（真偽値）/ %g（適切な数値形式）

### インポート
- 他パッケージを使うために必要（未使用はエラー）
- 書き方
  - 個別記述（非推奨）
  - グループ記述（推奨：可読性向上・gofmtで整形）
- 特殊：`_`
  - 副作用（初期化目的）で使用（通常は非推奨）

### エクスポート
- 外部公開の仕組み
  - 大文字開始：公開
  - 小文字開始：非公開
- 理由：シンプル / 読みやすい / 書きやすい

### 関数
- 処理をまとめた再利用可能な単位
- `func`で定義
- 引数：名前 → 型 / 戻り値：後ろに記述
- main関数：引数なし・戻り値なし

### 複数戻り値・名前付き戻り値
- 複数値を返せる（エラー処理・複数結果・構造体不要）
- `_`で不要な戻り値を無視（ブランク識別子）
- 名前付き戻り値
  - returnのみで返却可能
  - 短い関数・ドキュメント用途で使用（可読性に注意）

### 変数
- データを保存する箱
- 宣言方法
  - var：型明示・ゼロ値初期化
  - `:=`：型推論（関数内のみ）
- スコープ：パッケージ / 関数
- 命名：キャメルケース・意味のある名前

### 型
- データの種類を定義

#### 基本型
- bool / string
- int / int8 / int64 / uint
- float64 / complex
- byte / rune

#### 型推論
- 整数 → int
- 小数 → float64
- 文字列 → string
- 文字 → rune

### ゼロ値
- 宣言時に自動で初期化
  - int：0 / float：0.0 / string："" / bool：false
- メリット：安全性向上 / バグ削減

### 型変換
- 自動変換なし（明示的に行う）
  - 例：`int(x)`
- メリット：意図が明確 / バグ防止

### 定数
- 変更不可の値（`const`）
- コンパイル時チェック
- メリット：バグ早期発見 / マジックナンバー防止
- ルール
  - `:=`は使用不可
  - 実行時の値は不可

### 型なし定数
- 文脈によって型決定
- 柔軟に扱える

### ベストプラクティス
- 型推論を基本に使う
- 必要な場合のみ型を明示
- 定数を活用
- シンプルに書く
