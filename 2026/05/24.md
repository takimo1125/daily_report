## わかったこと
### コンテナ / Docker

Dockerとは、アプリケーションとその実行環境（ライブラリ・設定など）をまとめて管理できる仕組み。

- コンテナ：アプリケーションの実行環境
- イメージ：コンテナの設計図
- Docker：イメージの作成・実行・管理を行うツール

### CI/CD

開発からデプロイまでを自動化する仕組み。

#### CI（Continuous Integration）
- コードを定期的に統合
- 単体テストを実行
- バグの早期発見

#### CD（Continuous Delivery / Deployment）
- テスト済みコードを自動でデプロイ
- 本番・ステージング環境へ反映

### AWS 基礎（ネットワーク）

#### VPC
AWS上の仮想ネットワーク（仮想データセンター）

#### サブネット
VPCを分割したネットワーク領域

- パブリックサブネット
- プライベートサブネット

#### セキュリティグループ
通信のルール（仮想ファイアウォール）

- インバウンド / アウトバウンド通信制御

#### Route 53
- ドメイン管理
- DNSルーティング

#### ACM（AWS Certificate Manager）
- HTTPS用SSL/TLS証明書の発行・管理

#### ALB（Application Load Balancer）
- リクエストを複数のターゲットへ振り分け
- 負荷分散を実現

### ECS（Elastic Container Service）

AWSのフルマネージドなコンテナオーケストレーションサービス

- Dockerコンテナの実行・管理を簡略化
- インフラ管理の手間を削減
- ECRと連携可能

#### ECSの構成要素

- クラスター：タスクやサービスのグループ
- タスク定義：コンテナの設計書（CPU・メモリ・イメージなど）
- タスク：実際に動作しているコンテナ
- サービス：タスクの起動・維持・ALB連携を担当

#### ECSの起動タイプ

##### EC2起動タイプ
- EC2インスタンス上でコンテナ実行
- SSHログイン可能
- ホスト管理が必要

##### Fargate
- サーバー管理不要
- コンテナ実行のみを意識すればよい
- 基本的にFargateが推奨

#### デプロイ方式

##### ローリングアップデート
- 古いタスクを動かしながら順次新しいタスクへ切替

##### ブルー/グリーンデプロイ
- 新環境を作成
- トラフィックを一括で切り替え

### ECR（Elastic Container Registry）

- Dockerイメージの保存先
- ECSと連携して利用

### ECSとEKSの違い

#### ECS
- AWS独自のコンテナサービス
- シンプルで運用が容易
- 学習コストが低い

#### EKS（Kubernetes）
- Kubernetesベース（OSS）
- 高い拡張性・柔軟性
- 学習・運用コストが高い
- GitOpsと相性が良い

### IAM（Identity and Access Management）

#### IAMポリシー
- AWSリソースに対するアクセス権限を定義

#### IAMロール
- AWSサービスやリソースに付与する権限セット

#### ECS関連のIAMロール

##### タスクロール
- コンテナ内アプリがAWSリソースへアクセスするための権限
- 例：S3アクセス、DBアクセス

##### タスク実行ロール
- ECSが内部的に使用するロール
- 例：ECRからイメージ取得、CloudWatchログ出力

### GitHub Actions（CI/CD）

GitHub Actionsは、GitHub上のイベントをトリガーにワークフローを自動実行するCI/CDサービス。

#### 特徴
- GitHubリポジトリと強く連携
- YAMLファイルでワークフローを定義
- 仮想マシン（ランナー）上で実行

#### できること
- コードのビルド
- 単体テスト・結合テストの実行
- Dockerイメージのビルド・ECRへのpush
- ECS / EC2 / S3 / Lambda などへのデプロイ

#### トリガー例
- push時
- pull request作成時
- mainブランチへのマージ
- 手動実行（workflow_dispatch）

#### 一般的な構成
- jobs：処理の単位
- steps：実行手順
- actions：再利用可能な処理（公式・自作）

#### CI/CDでの役割
- CI：テスト・ビルドの自動化
- CD：デプロイの自動化（ECS連携など）

### VPCエンドポイント

- プライベートサブネットからAWSサービスへ安全にアクセス
- インターネットを経由せず通信可能
